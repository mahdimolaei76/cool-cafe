# عکس‌های پیش‌فرض منو

هر فایل تصویر (.jpg, .png, .webp) که در این پوشه قرار بگیرد،
به‌صورت خودکار در پنل مدیریت → ایجاد/ویرایش آیتم منو نمایش داده می‌شود.

## نحوه کار
- بک‌اند پوشه را اسکن می‌کند: `GET /api/menu/default-images`
- فرانت تصاویر را از: `GET /images/defaultMenuImages/<filename>` دریافت می‌کند
- نیازی به ویرایش کد نیست — فقط فایل را اینجا بگذارید.

## متغیر محیطی
```
STATIC_DIR=./static   # مسیر پیش‌فرض
```
